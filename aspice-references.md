# Automotive SPICE (ASPICE) Process Model — Key References

## 1. VDA Quality Management Center — Official ASPICE Home

**URL:** <https://vda-qmc.de/en/automotive-spice/>

The authoritative source maintained by the VDA (the German Association of the Automotive Industry). This is where the official Automotive SPICE 4.0 specification lives, along with news on updates and assessor guidelines.

## 2. Automotive SPICE 4.0 Process Reference Model (PDF)

**URL:** <https://automotivespice.com/fileadmin/software-download/automotiveSIG_PRM_v45.pdf>

The official Process Reference Model document detailing the 32 processes organized into 3 categories and 11 groups, including the purpose and outcomes of each process.

## 3. UL Solutions — Automotive SPICE 4.0 Pocket Guide (PDF)

**URL:** <https://www.ul.com/sites/default/files/2024-10/Automotive_Spice_Pocket_Guide.pdf>

A concise quick-reference guide summarizing the Process Assessment Model, capability levels (0–5), and key process indicators — handy for practitioners and assessors.

## 4. Expleo — Automotive SPICE 4.0 Process Guide & Workbook (PDF)

**URL:** <https://expleo.com/global/en/wp-content/documents/ASPICE%20BOOKLET_DIGI%204.0.pdf>

A practical implementation guide from Expleo covering ASPICE 4.0, including the newer hardware engineering and machine learning process groups added in the latest version.

## 5. SPKAA — A Comprehensive Guide to Automotive SPICE (PDF)

**URL:** <https://www.spkaa.com/wp-content/uploads/2023/12/A-Comprehensive-Guide-to-Automotive-SPICE.pdf>

A detailed technical guide covering the two-dimensional framework (process dimension and capability dimension), implementation strategies, and maturity assessment approaches.
